# MNIST Adversarial Attack Homework

This project trains a CNN model on MNIST and attacks it using:

- FGSM
- I-FGSM / PGD
- Momentum I-FGSM

## Dataset

MNIST dataset from torchvision.

Train part is used for training.  
Test part is used for testing.
